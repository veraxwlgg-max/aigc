# 检测流程

本目录按照论文全文 AIGC 检测的执行顺序组织代码。每一层独立保存脚本、测试和结果说明；含论文正文的实际输出只保留在各层的 `results/local/`，不提交到公共仓库。

```text
检测流程/
├── README.md
├── 01_文档清理/
│   ├── scripts/         # DOCX 结构解析与正文筛选
│   ├── tests/           # 合成单元测试
│   └── results/         # 可公开测试摘要；local/ 为私有全文结果
└── 02_规则检测/
    ├── scripts/         # R01–R05 检测、格式注入与验收
    ├── tests/           # 合成单元测试
    ├── test_documents/  # 仅提交说明；测试 Word 留在本地
    └── results/         # 可公开测试摘要；local/ 为私有全文结果
```

当前执行顺序：

1. `01_文档清理`：读取原生 DOCX，保留摘要、正文和参考文献，排除图表、标题、独立公式等非检测内容；
2. `02_规则检测`：读取第一层的结构化结果，输出 JSONL、汇总 JSON 和 HTML 人工复核报告。

后续零样本检测、模型融合和文档级汇总应继续按编号增加目录，不与数据集构建脚本混放。
