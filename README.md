# 中文学术文本 AIGC 检测

本项目研究中文学术文本中的 AIGC 检测问题，重点关注纯 AI 生成、AI 润色和人机混合写作场景。

项目现阶段不假设存在能够检测所有 AI 使用的“万能检测器”，而是通过可控数据和严格评测，分析已有方法在中文学术文本上的能力边界。

## 核心研究问题

1. 现有检测方法能否区分中文人类文本与纯 AI 生成文本？
2. 经过轻度 AI 润色后，检测性能会下降多少？
3. 检测器能否泛化到训练时未见过的模型、学科和文本类型？
4. 在严格控制误报率时，现有方法还具有多少实际检测能力？

- [检测流程](检测流程/README.md)：面向论文全文的文档清理、规则检测及后续检测层。
