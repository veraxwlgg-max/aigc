# 学术论文全文 AIGC 规则层设计

适用对象为中文学术论文的摘要、正文连续段落和参考文献。系统先按章节识别结构，再以句子、三句窗口、段落和单条参考文献为基本检测单元。

## 1. 分级

| 级别 | 含义 | 处理 |
|---|---|---|
| L3 | 直接证据 | 直接标记“高度疑似 AI” |
| L2 | 强可疑证据 | 作为高权重规则 |
| L1 | 辅助证据 | 单独不判 AI，只保留命中和原始特征 |
| X | 例外或无效文本 | 屏蔽规则或停止检测 |

## 2. 预处理

| 步骤 | 实现方法 |
|---|---|
| 结构分区 | 识别摘要、正文各章节和参考文献；标题、作者信息、关键词、章节标题、图表、附录、致谢及出版元数据标记为非检测区域 |
| 公式标记清理 | 审计文本保留 `[公式]`；规则分析副本将其替换为等长空格，再进行分句和特征计算。标记本身不进入 R01–R05、句长统计、重复统计或语义模型 |
| 段落与句子切分 | 在各章节内按空行分段，再按 `。！？；.!?;` 分句，保留章节、段落与原文字符范围 |
| 组窗 | 以“前句 + 当前句 + 后句”构造 3 句窗口，不跨段落、章节或结构区域 |
| 参考文献切分 | 按编号、换行和著录字段切分为单条参考文献；保留原始编号和字符范围，编号及固定著录标点不作为风格特征 |
| 执行顺序 | `X 类例外 → R01–R05 检测 → 句/段级输出` |

## 3. 核心规则

| ID | 规则 | 级别 | 检测内容 | 实现方法 | 粒度 |
|---|---|---|---|---|---|
| R01 | 模型/生成任务残留 | L3 | “作为 AI/语言模型”、“以下是润色后的内容/正文/段落/摘要”、“根据您的要求”、`User:`、`Assistant:`等 | 短语词典 + 正则；保留命中原文和字符范围 | 句子/段落 |
| R02 | AI 回答格式与 Markdown 残留 | L3 | 回答式开头/结尾，以及标题、强调、引用、列表、链接、图片、代码、表格、分隔线、脚注、HTML、数学分隔符等 Markdown 源格式 | 27 类格式信号独立检测；任意一种单独出现即触发 L3，并保留具体 `signal`、命中原文和字符范围；参考文献编号不触发编号列表规则 | 段落 |
| R03 | 句式节奏过度规整 | L1 | 句长过度均匀、逗号间子句长度过度均匀、标点序列重复、排比项过度对称 | 计算句长 CV、子句长度 CV、标点序列重复率和排比项对称度 | 窗口/段落 |
| R04 | 字面与语义冗余 | L2/L1 | 句首重复、3–5 gram 重复、相邻句语义高相似 | 字面重复与冻结中文句向量并行计算；两类证据同时命中为 L2，只命中一类为 L1 | 窗口/段落 |
| R05 | 空泛评价与证据缺失 | L1 | “显著提高/有效改善/具有重要意义/广阔前景”等结论与数值、指标、对比对象是否共现 | 先定位评价词，再搜索同句和相邻句中的数字、百分比、单位、指标名和比较词 | 句子/窗口 |

### R02 实际检测清单

下表列的是检测器实际在抽取文本中查找的字符，而不是 Word 的视觉样式。所有子规则只要单独命中一次，就产生一条 L3 证据。

| 序号 | `signal` | 实际检测形式 | 可命中的原文示例 |
|---:|---|---|---|
| 1 | `markdown_front_matter` | 文首由两行 `---` 包围，内部至少有一个 `字段: 值` | 第一行 `---`，第二行 `title: 论文标题`，第三行 `---` |
| 2 | `markdown_heading` | 行首 1–6 个 `#`，其后有空格和正文 | `### 实验结果` |
| 3 | `markdown_setext_heading` | 标题下一行只由至少三个 `=` 或 `-` 构成 | 第一行 `实验结果`，第二行 `---` |
| 4 | `markdown_bold_italic` | 文字两侧实际保留三个星号或三个下划线 | `***重点内容***`、`___重点内容___` |
| 5 | `markdown_bold` | 文字两侧实际保留两个星号或两个下划线 | `**重点内容**`、`__重点内容__` |
| 6 | `markdown_italic` | 文字两侧实际保留一个星号或一个下划线 | `*变量说明*`、`_变量说明_` |
| 7 | `markdown_strikethrough` | 文字两侧实际保留两个波浪号 | `~~删除内容~~` |
| 8 | `markdown_blockquote` | 行首 `>`；同时覆盖 Markdown 提示块 | `> 引用内容`、`> [!NOTE] 注意事项` |
| 9 | `markdown_task_list` | 行首项目符号后出现 `[ ]`、`[x]` 或 `[X]` | `- [x] 已完成实验` |
| 10 | `bullet_list` | 行首出现 `-`、`+`、`*`、`•`、`●` 或 `▪`，符号后有空格和文字 | `- 第一点`、`+ 第二点` |
| 11 | `numbered_list` | 行首数字或中文数字后接 `.`、`)`、`、` 等编号符 | `1. 第一点`、`一、研究背景` |
| 12 | `markdown_image` | `![说明](地址)` 图片源语法 | `![模型结构](figure.png)` |
| 13 | `markdown_link` | `[文字](地址)` 行内链接源语法 | `[项目主页](https://example.org)` |
| 14 | `markdown_reference_link` | `[文字][标签]` 引用式链接；第二个标签不能只是数字 | `[项目主页][project]` |
| 15 | `markdown_link_definition` | 行首 `[标签]: URL` | `[project]: https://example.org` |
| 16 | `markdown_autolink` | 尖括号包围的 HTTP/HTTPS 地址 | `<https://example.org>` |
| 17 | `markdown_fenced_code` | 行首三个以上反引号或波浪号，可带语言名 | 三个反引号后接 `python`，或行首 `~~~` |
| 18 | `markdown_inline_code` | 文字两侧实际保留单个反引号 | ``调用 `detect()` 函数`` |
| 19 | `markdown_table` | 表格分隔行，由竖线和至少三个连字符构成，可带冒号对齐 | `\| --- \| :---: \|` |
| 20 | `markdown_horizontal_rule` | 整行只有至少三个 `*`、`-` 或 `_`，中间可有空格 | `***`、`---`、`___` |
| 21 | `markdown_footnote` | `[^标签]`，也覆盖后接冒号的脚注定义 | `结论已有说明[^1]`、`[^1]: 数据来源` |
| 22 | `markdown_raw_html` | HTML 注释或常见成对/单独标签 | `<!-- 注释 -->`、`<details>`、`<br>`、`<table>` |
| 23 | `markdown_math_delimiter` | 公式两侧实际保留 `$` 或 `$$` | `$L=N/D$`、`$$E=mc^2$$` |
| 24 | `markdown_escape_sequence` | 反斜杠后紧跟 Markdown 特殊字符 | `\*不是列表\*`、`\#不是标题` |
| 25 | `frequent_blank_lines` | 同一文本块中连续出现两个以上换行，即中间形成空白行 | `第一段。` 后空一行再出现 `第二段。` |
| 26 | `answer_heading` | 文本块开头出现回答式引导语 | `以下是优化后的正文`、`回答如下`、`根据您的要求` |
| 27 | `closing_suggestion` | 文本块结尾出现面向用户的继续服务或建议 | `如需进一步说明，可以继续补充。`、`希望以上内容对您有所帮助。` |

R02 采用强规则：每个子规则单独命中即为 L3。这里检测的是抽取文本中真实存在的 Markdown 源字符，例如 `**字体**` 和行首 `- 第一点`；Word 中仅通过工具栏设置、没有留下星号等源字符的正常加粗或斜体不触发。中文引号内仅作为语法示例出现的标记予以保护；代码围栏、反引号和数学分隔符本身属于本规则的检测对象，不再作为保护区。该设置优先提高召回率，可能把论文中有意展示的 Markdown、代码或原始公式标为待复核证据。

## 4. 例外与质量规则

| ID | 规则 | 实现方法 | 处理 |
|---|---|---|---|
| X01 | 引用/语料/代码/公式保护 | 识别引号、语料样例、Prompt 模板、对话数据、代码、LaTeX 公式、`[公式]` 占位符和图表 | `[公式]` 在检测前从分析文本中去掉；中文引号保护 R01、R02 示例文本；代码与公式内容仍保护 R01/R04 等内容规则，但其 Markdown 源标记可触发 R02 |
| X02 | 学科术语与常规表达保护 | 识别术语、缩写、实体和“本文提出/实验结果表明”等学科常规表达 | 从 R04 的字面重复中排除，不直接判为人类 |
| X03 | 非检测区域与抽取噪声 | 识别标题、作者与单位、关键词、章节标题、图表及图注、独立公式、代码、附录、致谢、目录、页眉页脚、出版元数据，以及截断、OCR 乱码和重复抽取 | 停止该区域检测；参考文献不在排除范围内 |
