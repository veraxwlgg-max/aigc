# 第一步：数据清理

## 处理范围

输入仅支持原生 `.docx`。PDF 的解析、OCR 与版面拆解由上游系统负责，不属于本清洗模块。

保留：

- 摘要正文；
- 引言至结论之间的连续自然语言段落；
- 参考文献，每条作为独立文本块。

排除：

- 论文标题、作者、单位、关键词和出版元数据；
- 章节标题与小标题；
- 图片、表格、图注和表注；
- 独立公式、代码、伪代码和非连续分点列表；
- 附录、致谢、页眉、页脚和页码。

清洗只处理版面噪声和结构区域，不改写正文中的词语、句式或标点。

Word 行内公式不解析其具体内容，统一替换为 `[公式]`，并在 JSON
中记录 `contains_inline_formula` 和 `inline_formula_count`。纯公式段整段排除。
`[公式]` 仅用于审计；规则检测入口必须先将它替换为等长空格，不得将其作为格式、句长、重复或语义特征。

正文中实际残留的 Markdown/LaTeX 数学分隔符（例如 `$L=N/D$`）不会因含有公式字符而整段删除；自然语言正文保留并送入第二层 R02。只有几乎不含自然语言的独立公式块仍会排除。

## 安装

```bash
python3 -m pip install -r 数据处理/01_数据清理/requirements.txt
```

## 使用

```bash
python3 数据处理/01_数据清理/scripts/clean_academic_document.py \
  /path/to/paper.docx
```

每篇论文生成两个文件：

- `<文件名>.cleaned.txt`：送入后续检测器的清洗文本；
- `<文件名>.cleaned.json`：逐块记录章节、是否保留、排除原因，以及清洗文本中的字符范围。

默认写入 `results/local/`。该目录可能包含论文正文，只保存在本地；`results/test_summary.json` 保存可提交 GitHub 的脱敏测试结果。

`.doc` 和 `.pdf` 不会在本模块内自动转换；输入前应由上游系统统一产出 `.docx`。
